# Reddit Scraping Practice

This branch contains experimental and practice code for scraping Reddit data using Python and PRAW. Here, I explore basic data collection techniques, including:

- Retrieving posts and comments from subreddits (e.g., r/fragrance)
- Basic data cleaning and formatting
- Preliminary sentiment analysis using NLTK’s VADER
- Initial entity extraction with spaCy

The code in this branch serves as a sandbox to test and iterate on various data scraping and processing methods before integrating them into the main project.
